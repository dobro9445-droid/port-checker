
# Port Checker GUI

Графический порт-чекер для проверки и временного открытия портов.

Поддерживает популярные порты:

- веб-серверы: HTTP, HTTPS, 8080, 8443;
- Steam: игровые серверы, загрузки, Remote Play;
- EA / Origin;
- Minecraft, Terraria, Valheim, Rust, ARK, CS/Source, FiveM, TeamSpeak, Discord и другие.

## Запуск из исходников

```bash
python port_checker_gui.py
